# form-sales-bot

営業リスト（Excel）の各社について、公式サイトから問い合わせフォームを探し、自社情報と営業文面を **入力するところまで** 行うツールです。
**送信ボタンは押しません**（送信機能そのものを入れていません）。

## できること

1. リストの「公式情報URL」から、問い合わせページを自動で探します
   - 「お問い合わせ」「Contact」などのリンクを点数付けして順に開きます
   - 採用・査定・見積・来店予約など、営業向きでないフォームは後回しにします
   - 見つからなければ `/contact/` `/inquiry/` などのよくあるURLを試します
2. ページに「営業目的のお問い合わせはご遠慮ください」などの記載があれば **入力せずに「禁止」** と記録します
3. CAPTCHA（reCAPTCHA など）があれば記録します（突破はしません）
4. 入力欄を判定して埋めます（姓名分割・フリガナ・電話3分割・確認用メール・種別選択・同意チェックに対応）
   - `ANTHROPIC_API_KEY` が設定されていれば Claude で欄を判定し、なければルールで判定します
5. 入力後の画面をスクリーンショットに撮り、結果を Excel に書き戻します

## 結果の書き込み先（元ファイルは変更しません）

`リスト名_チェック結果.xlsx` が新しく作られます。

| 列 | 書き込む値 |
|---|---|
| 問い合わせURL | 見つかったフォームのURL |
| 問い合わせページ確認 | 確認済 / ページなし / 未確認（エラー時） |
| 営業利用可否 | 禁止（お断り記載あり）/ 未確認（記載なし。最終判断は人が行う） |
| 送信ステータス | **変更しません** |
| 備考 | `[自動]` で始まる行を追記 |

「自動チェック詳細」シートに、入力した項目・空いている必須項目・CAPTCHA・スクショのパスが入ります。
`営業利用可否` を自動で「利用可」にすることはありません。

## セットアップ（初回のみ）

Node.js 20 以上が必要です。

```bash
npm install
npm run setup          # Chromium のダウンロード
cp config.example.json config.json
```

`config.json` の `sender`（自社情報）と `subject` / `message`（文面）を書き換えてください。
文面では `{{企業名}}` `{{確認できた事業}}` `{{営業切り口}}` がリストの値に置き換わります。
`{{自分の名前}}` `{{自社名}}` `{{部署}}` `{{電話}}` `{{メール}}` は `sender` の値に置き換わります。
本文がフォームの文字数上限（maxlength）を超える場合は、`messageShort`（短縮版）に自動で切り替えます。短縮版でも超える場合は切り詰めて入力し、結果に「文字数オーバー」と記録します。

Claude で入力欄を判定する場合（任意）:

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

## 使い方

```bash
# まず数社で試す（ブラウザ画面を表示して動きを見る）
node src/index.js --input 営業リスト.xlsx --only 1,2,3 --headed

# 全件
node src/index.js --input 営業リスト.xlsx
```

| オプション | 説明 |
|---|---|
| `--input` | 営業リストの xlsx（必須） |
| `--output` | 結果ファイルの保存先（省略時は `入力名_チェック結果.xlsx`） |
| `--only 1,5,7` | No 列で対象を絞る |
| `--limit 10` | 先頭から N 社だけ |
| `--headed` | ブラウザを表示して実行 |
| `--config` | 設定ファイル（既定 `config.json`） |

「送信済」の行は自動で対象外になります。1社ごとに `settings.delayMs`（既定4秒）待ちます。
